# Лабораторная работа №2 — HTML и CSS

**Тема сайта:** «Чернота уголовников» — архив с досье на опасных преступников.

**Страницы** (папка `lab2`): `index.html`, `criminals.html`, `dossier.html`.
**Стили:** `style.css` (отдельный подключаемый файл). **Картинки:** `images/`.

Использованы: блочные и строчные элементы, ссылки, картинки, таблицы с выравниванием
по левому/правому краю и по центру, селекторы (элемента, класса, id, потомка, псевдокласса).
JS и библиотеки не используются.
